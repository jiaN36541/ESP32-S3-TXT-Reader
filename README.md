# ESP32-S3 TXT Reader

An ESP32-S3 based TXT e-book reader project.

## Features

- TXT file reading
- TFT color display
- SD card storage support
- UTF-8 text support
- Physical button control
- Reading progress management

## Hardware

- ESP32-S3 development board
- TFT display
- SD card module
- W25Q128 Flash memory
- Physical buttons

## Software

- Arduino IDE
- Arduino framework
- C/C++
